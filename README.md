# Real or Fake News Detector

A machine learning-based web application that classifies news articles as either **Real** or **Fake**. 

The project uses a Natural Language Processing (NLP) pipeline with TF-IDF vectorization and a Logistic Regression model trained on a dataset of news articles. It features a FastAPI backend for handling predictions and a clean HTML/CSS/JS frontend for user interaction.

## Features

- **Text Classification**: Input any news article or snippet of text to determine its authenticity.
- **FastAPI Backend**: High-performance asynchronous backend providing a RESTful API.
- **Machine Learning**: Utilizes Scikit-Learn's `TfidfVectorizer` and `LogisticRegression`.
- **Responsive UI**: Simple, user-friendly frontend to interact with the prediction model.

## Tech Stack

- **Backend**: Python, FastAPI, Uvicorn, Scikit-Learn, Pandas, Joblib
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Machine Learning**: NLP (TF-IDF), Logistic Regression

## Setup and Installation

### Prerequisites

- Python 3.8+
- Node.js / Live Server (optional, for serving the frontend easily)

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd "Real or Fake"
```

### 2. Backend Setup
Navigate to the backend directory and install the required Python packages.
```bash
cd backend
pip install -r requirements.txt
```

### 3. Model Training (Optional)
If `model.pkl` and `vectorizer.pkl` are not present in the root directory, you will need to train the model. Make sure `news.csv` is in the root directory.
```bash
python train_model.py
```
This script will read the dataset, train the Logistic Regression model, and generate the necessary `.pkl` files in the root directory.

### 4. Running the Backend Server
Start the FastAPI server using Uvicorn.
```bash
# Still in the backend directory
python main.py
```
The backend API will be available at `http://localhost:8000`. You can view the interactive API documentation at `http://localhost:8002/docs`.

### 5. Running the Frontend
You can simply open `frontend/index.html` in your web browser. Alternatively, for a better development experience, you can serve the frontend directory using a simple HTTP server (e.g., using VS Code Live Server, or Python's built-in http.server).
```bash
# Open a new terminal and navigate to the project root
cd frontend
# (Optional) Serve with python
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.

## API Endpoints

### `GET /`
- **Description**: Health check endpoint.
- **Response**: `{"message": "Send a POST request to /predict with JSON body {\"text\": \"...\"}"}`

### `POST /predict`
- **Description**: Predicts whether a given news text is real or fake.
- **Request Body**: JSON containing the text field.
  ```json
  {
    "text": "Your news text goes here..."
  }
  ```
- **Response**: JSON containing the prediction label and raw score.
  ```json
  {
    "prediction": "Real",
    "raw_score": 1
  }
  ```
